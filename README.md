# Student Performance Prediction Using Machine Learning

## Problem Statement
The project aims to predict student mathematics performance using machine learning algorithms and compare their effectiveness in classifying students into performance categories.

## Objective
- Analyze the student performance dataset.
- Preprocess the data and transform categorical features.
- Build machine learning models.
- Compare model performance using evaluation metrics.
- Visualize the results.

## Dataset
The dataset contains student information, including gender, race or ethnicity, parental education, lunch type, test preparation course, and mathematics, reading, and writing scores.

## Algorithms Used
1. Decision Tree Classifier
2. K-Nearest Neighbors (KNN) Classifier
3. Support Vector Machine (SVM) Classifier

## Evaluation Metrics
Accuracy, Precision, Recall, and F1-score.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project File
`StudentsPerformanceProject.ipynb`

## How to Run
1. Open the notebook in Google Colab.
2. Load the `StudentsPerformance.csv` dataset.
3. Run the notebook cells in order.
4. Review the model evaluation results and visualizations.
